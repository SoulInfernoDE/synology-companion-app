The first preview of **Syno Companion**, an independent, open-source desktop companion for Synology NAS on Linux, macOS and Windows. It is a pre-release: the basics work and are tested against a Virtual DSM 7.4.1, but not yet on many models.

## What it does

- **Finds NAS** on the local network through Bonjour and through Synology Assistant's own search, so NAS without Bonjour show up, too. You can always enter an address.
- **Sets up a new NAS** whose DSM welcome wizard has not run yet: your own administrator account, the built-in `admin` account locked, device name, time zone and updates, usage statistics off. It warns that until then anyone on the network can manage the NAS.
- **Signs in** through the DSM Web API with two-step verification and "remember this computer". DSM's self-signed certificate is shown by its SHA-256 fingerprint and pinned once you trust it; a changed certificate brings a clear warning.
- **Keeps secrets in the system keychain** (Secret Service, macOS Keychain, Windows Credential Manager), never in a file.
- **Dashboard:** processor with architecture, cores and clock; memory; network traffic and every port with its link speed; volumes with RAID type, file system and usage; drives with health, temperature and whether they are on Synology's compatibility list.
- **Looks at home on every system:** skins for Linux, macOS and Windows in light and dark, following the system or chosen by hand. English and German.

## Downloads

- **Linux:** `.deb` for Debian, Ubuntu and Linux Mint; `.rpm` for Fedora and openSUSE; `.AppImage` runs without installing. Each for x86_64 and arm64. Built on Ubuntu 22.04, so glibc 2.35 or newer is needed.
- **macOS:** `syno-companion-0.1.0-macos-universal.dmg` for Apple silicon and Intel. Not notarised yet: open it with right-click › Open the first time. macOS asks once for access to the local network.
- **Windows:** `-setup.exe` (per user) or `.msi` (system-wide). Not signed yet, so SmartScreen may warn; choose _More info › Run anyway_. Windows Firewall may ask about the network search.

Verify the downloads with `sha256sum -c SHA256SUMS.txt`.

## Known limits

- Memory type and modules, and network chips, are not reported by the DSM Web API; they come with the SSH diagnostics in 0.3.
- Drives and temperature are not tested on real hardware yet (a Virtual DSM has neither).
- Shared folders, packages, SSH, extensions and Nextcloud are shown as planned sections. See the [roadmap](https://github.com/SoulInfernoDE/synology-companion-app/blob/main/ROADMAP.md).

## Deutsch

Die erste Vorschau von **Syno Companion**, einem unabhängigen, quelloffenen Desktop-Begleiter für Synology-NAS unter Linux, macOS und Windows. Es ist eine Vorabversion: Die Grundlagen funktionieren und sind an einem Virtual DSM 7.4.1 getestet, aber noch nicht an vielen Modellen.

### Was sie kann

- **Findet NAS** im lokalen Netz über Bonjour und über die eigene Suche des Synology Assistant, sodass auch NAS ohne Bonjour erscheinen. Eine Adresse lässt sich immer eingeben.
- **Richtet ein neues NAS ein**, dessen DSM-Willkommensassistent noch nicht gelaufen ist: eigenes Administratorkonto, eingebautes Konto `admin` gesperrt, Gerätename, Zeitzone und Updates, Nutzungsstatistiken aus. Sie warnt, dass bis dahin jeder im Netzwerk das NAS verwalten kann.
- **Meldet sich an** über die DSM-Web-API, mit Bestätigung in zwei Schritten und „Diesen Computer merken“. DSMs selbstsigniertes Zertifikat wird mit seinem SHA-256-Fingerabdruck gezeigt und nach dem Vertrauen festgehalten; ein geändertes Zertifikat führt zu einer deutlichen Warnung.
- **Bewahrt Geheimnisse im Schlüsselbund des Systems auf** (Secret Service, macOS-Schlüsselbund, Windows-Anmeldeinformationsverwaltung), nie in einer Datei.
- **Übersicht:** Prozessor mit Architektur, Kernen und Takt; Arbeitsspeicher; Netzwerkverkehr und jeder Port mit seiner Link-Geschwindigkeit; Volumes mit RAID-Typ, Dateisystem und Belegung; Laufwerke mit Zustand, Temperatur und ob sie auf Synologys Kompatibilitätsliste stehen.
- **Passt zu jedem System:** Skins für Linux, macOS und Windows in Hell und Dunkel, wie das System oder von Hand gewählt. Englisch und Deutsch.

### Downloads

- **Linux:** `.deb` für Debian, Ubuntu und Linux Mint; `.rpm` für Fedora und openSUSE; `.AppImage` läuft ohne Installation. Jeweils für x86_64 und arm64. Gebaut auf Ubuntu 22.04, daher wird glibc 2.35 oder neuer gebraucht.
- **macOS:** `syno-companion-0.1.0-macos-universal.dmg` für Apple Silicon und Intel. Noch nicht notarisiert: Beim ersten Mal mit Rechtsklick › Öffnen starten. macOS fragt einmal nach dem Zugriff auf das lokale Netzwerk.
- **Windows:** `-setup.exe` (pro Benutzer) oder `.msi` (systemweit). Noch nicht signiert, SmartScreen kann deshalb warnen; _Weitere Informationen › Trotzdem ausführen_ wählen. Die Windows-Firewall kann wegen der Netzwerksuche nachfragen.

Die Downloads prüfen mit `sha256sum -c SHA256SUMS.txt`.

### Bekannte Grenzen

- Speichertyp und -module sowie Netzwerkchips meldet die DSM-Web-API nicht; sie kommen mit der SSH-Diagnose in 0.3.
- Laufwerke und Temperatur sind noch nicht an echter Hardware getestet (ein Virtual DSM hat beides nicht).
- Freigaben, Pakete, SSH, Erweiterungen und Nextcloud erscheinen als geplante Bereiche. Siehe [Roadmap](https://github.com/SoulInfernoDE/synology-companion-app/blob/main/ROADMAP.de.md).
