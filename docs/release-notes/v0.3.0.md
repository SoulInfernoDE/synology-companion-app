The third preview of **Syno Companion**, an independent, open-source desktop companion for Synology NAS on Linux, macOS and Windows. Version 0.3 adds SSH: the app can now look deeper into the NAS than DSM's web interface allows. It is still a pre-release.

## New in 0.3

- **SSH with a key:** the new SSH section turns on DSM's SSH service if you agree, creates an ed25519 key for this computer and installs it on the NAS with your DSM password, once. The key is kept in the system keychain; the password is not needed again. The host key is pinned like the HTTPS certificate, and a changed key is refused with a warning. _Remove key_ takes it off the NAS and this computer again.
- **Diagnostics:** DSM build and update, kernel version and architecture, whether the kernel has `io_uring`, the driver and link speed of every network interface, the Docker version and the memory modules with size, type, speed, manufacturer and part number.
- **sudo without exposure:** commands that need root get the password on standard input, never on a command line. It comes from the keychain if you let the app remember it, otherwise you type it.
- **Terminal (expert mode):** a shell on the NAS inside the app, signed in with the key.

## Downloads

- **Linux:** `.deb` for Debian, Ubuntu and Linux Mint; `.rpm` for Fedora and openSUSE; `.AppImage` runs without installing. Each for x86_64 and arm64. Built on Ubuntu 22.04, so glibc 2.35 or newer is needed.
- **macOS:** `syno-companion-0.3.0-macos-universal.dmg` for Apple silicon and Intel. Not notarised yet: open it with right-click › Open the first time.
- **Windows:** `-setup.exe` (per user) or `.msi` (system-wide). Not signed yet, so SmartScreen may warn; choose _More info › Run anyway_.

Verify the downloads with `sha256sum -c SHA256SUMS.txt`.

## Known limits

- Only administrators can use SSH on DSM, and key sign-in needs DSM's user home service.
- The app uses a key of its own; importing an existing key is not planned.
- Updates are shown, not installed yet.

## Deutsch

Die dritte Vorschau von **Syno Companion**, einem unabhängigen, quelloffenen Desktop-Begleiter für Synology-NAS unter Linux, macOS und Windows. Version 0.3 bringt SSH: Die App kann jetzt tiefer in das NAS schauen, als es die Weboberfläche von DSM erlaubt. Es ist weiterhin eine Vorabversion.

### Neu in 0.3

- **SSH mit Schlüssel:** Der neue Bereich SSH schaltet den SSH-Dienst von DSM ein, wenn du zustimmst, erzeugt einen ed25519-Schlüssel für diesen Computer und installiert ihn einmalig mit deinem DSM-Passwort auf dem NAS. Der Schlüssel liegt im Schlüsselbund des Systems; das Passwort wird danach nicht mehr gebraucht. Der Host-Schlüssel wird wie das HTTPS-Zertifikat festgehalten, ein geänderter Schlüssel wird mit Warnung abgelehnt. _Schlüssel entfernen_ nimmt ihn wieder vom NAS und von diesem Computer.
- **Diagnose:** DSM-Build und Update, Kernel-Version und Architektur, ob der Kernel `io_uring` hat, Treiber und Verbindungsgeschwindigkeit jeder Netzwerkschnittstelle, die Docker-Version und die Speichermodule mit Größe, Typ, Takt, Hersteller und Teilenummer.
- **sudo ohne Preisgabe:** Befehle, die root brauchen, bekommen das Passwort über die Standardeingabe, nie in einer Befehlszeile. Es kommt aus dem Schlüsselbund, wenn du es die App merken lässt, sonst gibst du es ein.
- **Terminal (Expertenmodus):** eine Shell auf dem NAS direkt in der App, angemeldet mit dem Schlüssel.

### Downloads

- **Linux:** `.deb` für Debian, Ubuntu und Linux Mint; `.rpm` für Fedora und openSUSE; `.AppImage` läuft ohne Installation. Jeweils für x86_64 und arm64. Gebaut auf Ubuntu 22.04, daher wird glibc 2.35 oder neuer gebraucht.
- **macOS:** `syno-companion-0.3.0-macos-universal.dmg` für Apple Silicon und Intel. Noch nicht notarisiert: Beim ersten Mal mit Rechtsklick › Öffnen starten.
- **Windows:** `-setup.exe` (pro Benutzer) oder `.msi` (systemweit). Noch nicht signiert, SmartScreen kann deshalb warnen; _Weitere Informationen › Trotzdem ausführen_ wählen.

Die Downloads prüfen mit `sha256sum -c SHA256SUMS.txt`.

### Bekannte Grenzen

- Nur Administratoren können SSH auf DSM nutzen, und die Anmeldung mit Schlüssel braucht den Benutzer-Home-Dienst von DSM.
- Die App nutzt einen eigenen Schlüssel; einen vorhandenen zu importieren ist nicht geplant.
- Updates werden angezeigt, aber noch nicht installiert.
