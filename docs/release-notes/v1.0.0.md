**Syno Companion 1.0**, an independent, open-source desktop companion for Synology NAS on Linux, macOS and Windows. Since 0.2 it has learned to work on the NAS over SSH: install packages, update containers and Nextcloud, and run proven community scripts safely.

## New since 0.2

- **SSH with a key:** the app turns on DSM's SSH service if you agree, creates a key for this computer and installs it with your DSM password once. The host key is pinned like the HTTPS certificate. `sudo` gets its password on standard input, never on a command line.
- **Diagnostics:** DSM build, kernel, `io_uring`, network drivers, Docker, memory modules and the results of Synology Assistant's memory test.
- **Packages:** install and update packages from Synology and from sources such as SynoCommunity, with the packages they depend on. Package sources can be added in expert mode.
- **Containers:** see which containers of Container Manager run an older image than their tag offers, and update Compose projects.
- **Download Station:** follow downloads, add links, pause, resume and remove them.
- **Recipes (expert mode):** community scripts from a pinned release, checked against their checksum, with a backup first, a restore step and a journal on the NAS. The first recipe adds third-party drives to DSM's compatibility database (Synology_HDD_db by 007revad).
- **After a DSM update:** a notification about the new version, recipes the update removed are marked with the options of their last run, and an optional boot task applies them again without the app.
- **Nextcloud:** version, PHP, database and Redis of a Nextcloud in Web Station, a check of the PHP version against the next release, and a guided update in visible, resumable steps.
- **Terminal (expert mode):** a shell on the NAS inside the app.
- **Packaging:** the release workflow can sign and notarise; a Flatpak manifest and an AUR package are prepared.

## Downloads

- **Linux:** `.deb` for Debian, Ubuntu and Linux Mint; `.rpm` for Fedora and openSUSE; `.AppImage` runs without installing. Each for x86_64 and arm64. Built on Ubuntu 22.04, so glibc 2.35 or newer is needed.
- **macOS:** `syno-companion-1.0.0-macos-universal.dmg` for Apple silicon and Intel.
- **Windows:** `-setup.exe` (per user) or `.msi` (system-wide).

Verify the downloads with `sha256sum -c SHA256SUMS.txt`.

## Known limits

- Packages, containers, recipes and Nextcloud are tested against a stand-in DSM; please report what you see on real hardware.
- Updating Container Manager's Docker engine and starting the memory test from the app are not offered yet.

## Deutsch

**Syno Companion 1.0**, ein unabhängiger, quelloffener Desktop-Begleiter für Synology-NAS unter Linux, macOS und Windows. Seit 0.2 arbeitet er über SSH auf dem NAS: Pakete installieren, Container und Nextcloud aktualisieren und bewährte Community-Skripte sicher ausführen.

### Neu seit 0.2

- **SSH mit Schlüssel:** Die App schaltet den SSH-Dienst von DSM ein, wenn du zustimmst, erzeugt einen Schlüssel für diesen Computer und installiert ihn einmalig mit deinem DSM-Passwort. Der Host-Schlüssel wird wie das HTTPS-Zertifikat festgehalten. `sudo` bekommt sein Passwort über die Standardeingabe, nie in einer Befehlszeile.
- **Diagnose:** DSM-Build, Kernel, `io_uring`, Netzwerktreiber, Docker, Speichermodule und die Ergebnisse des Speichertests aus dem Synology Assistant.
- **Pakete:** Pakete von Synology und aus Quellen wie SynoCommunity installieren und aktualisieren, samt der Pakete, die sie brauchen. Paketquellen lassen sich im Expertenmodus hinzufügen.
- **Container:** sehen, welche Container von Container Manager ein älteres Image nutzen, als ihr Tag anbietet, und Compose-Projekte aktualisieren.
- **Download Station:** Downloads verfolgen, Links hinzufügen, anhalten, fortsetzen und entfernen.
- **Rezepte (Expertenmodus):** Community-Skripte aus einem festen Release, gegen ihre Prüfsumme geprüft, mit Sicherung vorher, Wiederherstellung und Journal auf dem NAS. Das erste Rezept trägt Laufwerke anderer Hersteller in DSMs Kompatibilitätsdatenbank ein (Synology_HDD_db von 007revad).
- **Nach einem DSM-Update:** eine Benachrichtigung über die neue Version, Rezepte, die das Update entfernt hat, werden mit den Optionen ihres letzten Laufs markiert, und eine optionale Startaufgabe wendet sie ohne die App erneut an.
- **Nextcloud:** Version, PHP, Datenbank und Redis eines Nextcloud in Web Station, eine Prüfung der PHP-Version gegen das nächste Release und ein geführtes Update in sichtbaren, fortsetzbaren Schritten.
- **Terminal (Expertenmodus):** eine Shell auf dem NAS direkt in der App.
- **Paketierung:** Der Release-Workflow kann signieren und notarisieren; ein Flatpak-Manifest und ein AUR-Paket sind vorbereitet.

### Downloads

- **Linux:** `.deb` für Debian, Ubuntu und Linux Mint; `.rpm` für Fedora und openSUSE; `.AppImage` läuft ohne Installation. Jeweils für x86_64 und arm64. Gebaut auf Ubuntu 22.04, daher wird glibc 2.35 oder neuer gebraucht.
- **macOS:** `syno-companion-1.0.0-macos-universal.dmg` für Apple Silicon und Intel.
- **Windows:** `-setup.exe` (pro Benutzer) oder `.msi` (systemweit).

Die Downloads prüfen mit `sha256sum -c SHA256SUMS.txt`.

### Bekannte Grenzen

- Pakete, Container, Rezepte und Nextcloud sind gegen ein Ersatz-DSM getestet; bitte melde, was du an echter Hardware siehst.
- Die Docker-Engine von Container Manager aktualisieren und den Speichertest aus der App starten wird noch nicht angeboten.
